SHERPA field assessment — release v1.0
USER DISTRIBUTION

Interface Developer: Pasquale Borrelli, September 2026

HOW TO START
1. Unzip the complete folder.
2. Open SHERPA_field_assessment_v1_0.Rproj in RStudio.
3. Open START_SHERPA.R.
4. Click Source.

Required R package:
  install.packages("shiny")

To use European raster data:
  install.packages("terra")

European raster files are not included in this package.
Select your Part 1 and Part 2 raster folders inside SHERPA.

Do not move or delete files inside the R, config, data or www folders.

Method reference:
Alewell, C., Gupta, S., Poulenard, J., Niquille, N., Kaiser, A., Shokri, N.,
